# plainblue Guitar privacy policy

Public static privacy information for the Android app plainblue Guitar.

- German: https://koma-xrd.github.io/plainblue-privacy/
- English: https://koma-xrd.github.io/plainblue-privacy/en.html
- Contact: support@plainblue.org

GitHub Pages publishes the root of the main branch. No build tools, external fonts, JavaScript, analytics or app source code are included. GitHub's hosting may process connection information as described in the policy.

Update both HTML documents together when app data handling changes; update their dates. Keep all styles local. Never add app recordings, backups, credentials or signing material to this repository. Provider details are supplied by the app publisher; the policy is not a legal certification.
